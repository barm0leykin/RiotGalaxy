## система памяти

в директории ai-agent/ реализована система сохранения контекста:

- **agent-memory.py** - основной модуль управления памятью
- **vector-index.py** - интеграционный модуль для работы с памятью и векторным индексом
- **main.py** - главный модуль для запуска AI агента с сохранением контекста
- **save-history.py** - модуль для сохранения истории работы агента
- **test_memory.py** - скрипт для тестирования системы памяти

### как использовать систему памяти

1. при старте новой сессии: создание сессии, загрузка контекста проекта, получение сводки последних действий
2. во время работы: сохранение сообщений, добавление выполненных задач в сводку, обновление информации о компонентах
3. при завершении: сохранение сессии в архив, обновление контекста проекта

### сохраняемые данные

- контекст проекта в project_context.json
- сводка выполненных действий в summary.txt
- история сообщений в sessions/
- компоненты проекта и важные файлы

### безопасность

не хранить в памяти конфиденциальные данные, пароли, токены и т.д.
