# AI Agent Memory System

Система сохранения контекста для AI агента, работающего над проектом RiotGalaxy.

## Функциональность

- Сохранение контекста проекта в директории `ai-agent/memory/`
- Отслеживание истории диалогов
- Индексация кода для быстрого поиска
- Восстановление состояния при следующем запуске

## Установка

1. Установите зависимости (для функции индексации кода):
```bash
pip install langchain openai chromadb tiktoken
```

2. Система будет работать и без этих зависимостей, но функция поиска по коду будет недоступна.

## Структура памяти

```
ai-agent/memory/
├── project_context.json     # Контекст проекта
├── summary.txt              # Сводка выполненных действий
├── current_session.json     # Информация о текущей сессии
└── sessions/                # Архив сессий
    ├── YYYYMMDD_HHMMSS.json              # Информация о сессии
    └── YYYYMMDD_HHMMSS_messages.jsonl    # История сообщений
```

## Использование

### Основной скрипт

Запуск главного модуля:
```bash
cd ai-agent
python main.py
```

### Тестирование

Запуск теста системы памяти:
```bash
cd ai-agent
python test_memory.py
```

### Программное использование

```python
from agent_memory import AgentMemory

# Создание экземпляра памяти
memory = AgentMemory()

# Добавление выполненной задачи
memory.add_task_completed("Создан компонент для авторизации")

# Обновление компонента проекта
memory.update_project_component("AuthService", "Сервис аутентификации")

# Добавление важного файла
memory.add_important_file("src/services/auth.service.ts", "Сервис аутентификации")

# Сохранение сообщения
memory.save_message("human", "Помоги с авторизацией")
memory.save_message("assistant", "Вот пример реализации...")

# Получение контекста для промпта
context = memory.get_context_for_prompt()

# Завершение сессии
memory.end_current_session()
```

### Использование с векторным индексом

```python
from vector_index import (
    index_code_folder,
    retrieve_code_context,
    get_context_for_prompt
)

# Индексация папки с кодом
index_code_folder("src")

# Поиск релевантного кода
code_context = retrieve_code_context("authentication")

# Получение полного контекста
full_context = get_context_for_prompt()
```

## Формат сводки

Сводка сохраняется в файл `summary.txt` в формате:
```
[YYYY-MM-DD HH:MM] Описание выполненного действия
```

Пример:
```
[2023-10-15 14:30] Создан компонент для авторизации JWT
[2023-10-15 15:45] Обновлен Dockerfile для сервиса auth
[2023-10-16 09:20] Добавлены тесты для UserService
```

## Интеграция с рабочим процессом

1. При запуске агента:
   - Создается новая сессия с уникальным ID
   - Загружается контекст проекта
   - Читается сводка последних действий
   - Индексируется код проекта (если настроено)

2. Во время работы:
   - Каждое сообщение сохраняется в историю
   - Выполненные задачи добавляются в сводку
   - Обновляется информация о компонентах проекта
   - При необходимости добавляются важные файлы

3. При завершении работы:
   - Сессия сохраняется в архив
   - Обновляется контекст проекта

## Преимущества

- **Сохранение контекста**: Агент "помнит" что было сделано ранее
- **Быстрое восстановление**: При следующем запуске агент может продолжить с того же места
- **Эффективность**: Избегает повторного чтения всего проекта
- **Организация**: Структурированное хранение информации о проекте

## Настройки

- Директория памяти: `ai-agent/memory/`
- Максимальное количество сообщений в контексте: 10
- Размер фрагментов для индексации: 1000 символов
- Перекрытие фрагментов: 200 символов

- Обновляйте информацию о важных компонентах проекта
- Индексируйте только релевантные файлы кода
