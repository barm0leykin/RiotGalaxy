# Быстрый старт с системой памяти агента

## Что это такое?

Система памяти для AI агента, которая позволяет сохранять контекст работы над проектом RiotGalaxy и восстанавливать его при следующих запусках.

## Как запустить

### Тестирование системы памяти

```bash
cd ai-agent
python test_memory.py
```

### Запуск агента с памятью

```bash
cd ai-agent
python main.py
```

### Использование обертки

```bash
cd ai-agent
python agent_wrapper.py
```

## Что происходит при запуске

1. Создается новая сессия с уникальным ID
2. Загружается контекст проекта
3. Индексируются файлы проекта (если установлены зависимости)
4. Сохраняется история сообщений

## Где сохраняется данные

Все данные сохраняются в директории `ai-agent/memory/`:
- `project_context.json` - информация о проекте
- `summary.txt` - сводка выполненных действий
- `sessions/` - архив сессий

## Что можно делать

```python
from agent_memory import AgentMemory

# Создаем память
memory = AgentMemory()

# Добавляем задачу
memory.add_task_completed("Создан новый компонент")

# Обновляем компонент
memory.update_project_component("Frontend", "React-приложение")

# Добавляем важный файл
memory.add_important_file("src/app.ts", "Основной файл приложения")

# Получаем контекст
context = memory.get_context_for_prompt()

# Завершаем сессию
memory.end_current_session()
```

## Начинаем работу

При первом запуске система создаст все необходимые файлы и директории. 
При следующих запусках она автоматически загружает сохраненный контекст,
позволяя агенту "помнить" что было сделано ранее.
