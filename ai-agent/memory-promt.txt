# Инструкции для AI агента по сохранению контекста

## Общие принципы
- Агент должен всегда сохранять контекст своей работы в директорию ai-agent/memory/
- Это позволяет восстанавливать состояние проекта и продолжать работу при следующем запуске
- Избегайте избыточных деталей, сохраняйте только существенную информацию

## Структура памяти

1. **ai-agent/memory/project_context.json** - контекст проекта
   - Название проекта
   - Тип проекта
   - Список компонентов
   - Важные файлы
   - Дата последнего изменения

2. **ai-agent/memory/summary.txt** - сводка выполненных действий
   - Хронологический список важных действий
   - Формат: [YYYY-MM-DD HH:MM] Описание действия
   - Пример: [2023-10-15 14:30] Создан новый компонент для аутентификации

3. **ai-agent/memory/sessions/** - архив сессий
   - Каждая сессия сохраняется в отдельном файле
   - Имя файла: YYYYMMDD_HHMMSS.json
   - Содержит информацию о сессии и выполненных задачах

4. **ai-agent/memory/sessions/YYYYMMDD_HHMMSS_messages.jsonl** - история сообщений
   - Все диалоги пользователя и агента
   - Каждое сообщение на отдельной строке в формате JSON

## Инструкции для агента

### Автоматическое сохранение
1. При старте новой сессии:
   - Создать новую сессию с уникальным ID
   - Загрузить контекст проекта
   - Получить сводку последних действий
   - Получить последние сообщения из предыдущей сессии

2. Во время работы:
   - Сохранять каждое сообщение в историю
   - После выполнения важной задачи - добавлять запись в сводку
   - При работе с важными файлами - добавлять их в контекст проекта
   - При изменении компонентов - обновлять информацию о них

3. При завершении сессии:
   - Сохранить информацию о сессии в архив
   - Обновить контекст проекта

### Примеры использования

#### Добавление задачи в сводку:
```python
memory.add_task_completed("Создан компонент для авторизации JWT")
```

#### Обновление компонента проекта:
```python
memory.update_project_component("AuthService", "Обеспечивает аутентификацию и авторизацию пользователей через JWT")
```

#### Добавление важного файла:
```python
memory.add_important_file("src/services/auth.service.ts", "Сервис аутентификации")
```

## Интеграция с рабочим процессом

1. **При получении запроса пользователя**:
   - Загрузить контекст из памяти
   - Сформировать промпт с учётом контекста
   - Сохранить запрос пользователя в историю

2. **При выполнении задачи**:
   - Выполнить требуемые действия
   - Добавить выполненную задачу в сводку
   - При необходимости обновить контекст проекта

3. **При формировании ответа**:
   - Сохранить ответ в историю
   - Вернуть ответ пользователю

## Формат контекста для промпта

При формировании промпта используйте метод `get_context_for_prompt()` который включает:
- Информацию о проекте
- Компоненты проекта
- Важные файлы
- Сводку последних действий
- Последние сообщения

## Восстановление контекста

При запуске новой сессии агент должен:
1. Загрузить контекст проекта из project_context.json
2. Прочитать последние записи из summary.txt
3. Прочитать последние сообщения из предыдущей сессии
4. Сформировать.prompts на основе этой информации

Это позволит агенту "помнить" что было сделано ранее и продолжить работу с того же места.
