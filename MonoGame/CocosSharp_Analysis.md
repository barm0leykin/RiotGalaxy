# Анализ архитектуры оригинального проекта RiotGalaxy (CocosSharp)

## Обзор

RiotGalaxy - это 2D космический шутер, реализованный на CocosSharp (Xamarin). Игра использует несколько ключевых архитектурных паттернов:

1. **Паттерн Стратегия** - для поведения объектов (движение, стрельба, отрисовка и столкновения)
2. **Паттерн Команда** - для управления событиями и состояниями игры
3. **Паттерн Состояние** - для AI врагов и состояний игры
4. **Фабричный паттерн** - для создания объектов

## Структура проекта

### Основные директории

```
RiotGalaxyShared/
├── App/                  # Приложение
├── Commands/             # Команды (паттерн Команда)
├── Factories/            # Фабрики для создания объектов
├── Interface/            # Пользовательский интерфейс
├── Objects/              # Игровые объекты
│   ├── Bonus/           # Бонусы
│   └── ObjBehavior/     # Компоненты поведения (паттерн Стратегия)
├── Scenes/               # Сцены CocosSharp
├── SFX/                  # Спецэффекты
├── Utils/                # Утилиты
└── Weapons/              # Оружие и снаряды
```

## Ключевые классы и их взаимодействие

### 1. GameManager.cs

**Назначение**: Центральный класс управления игрой.
**Ключевые функции**:
- Управление состоянием игры через `IGameState`
- Хранение глобальных объектов: `player`, `level`, `gameplay`
- Инициализация основных систем игры
- Обработка основного цикла игры через `ShActivity()`

**Важные свойства**:
```csharp
public static FileUtils fUtils;
public static Options opt;
public static IGameState state;
public static Level level;
public static Player player;
public static Gameplay gameplay;
public InputHandler userInputHandler;
```

### 2. GameObject.cs

**Назначение**: Базовый класс для всех игровых объектов. Наследуется от `CCNode` (CocosSharp).
**Компоненты поведения (паттерн Стратегия)**:
- `Weapon gun` - оружие объекта
- `ObjBehShoot shoot` - поведение стрельбы
- `BehMove move` - поведение движения
- `ObjBehCollision coll` - поведение столкновений
- `ObjBehDraw draw` - поведение отрисовки

**Важные методы**:
- `Activity(float time)` - основной цикл объекта
- `Collision(GameObject obj)` - обработка столкновений
- `Hit(int damage)` - получение урона
- `GetRect()` - получение ограничивающего прямоугольника

### 3. PlayerShip.cs

**Назначение**: Класс корабля игрока, наследуется от `GameObject`.
**Особенности**:
- Использует специфичные для игрока компоненты: `ObjBehPlayerMove`
- Поддерживает несколько типов оружия через `ChangeWeapon()`
- Имеет временную неуязвимость (`GodMode`) после получения урона
- Управляет здоровью и очками игрока

### 4. Enemy.cs

**Назначение**: Базовый класс для всех врагов, наследуется от `GameObject`.
**Особенности**:
- Использует компоненты AI для управления поведением
- Поддерживает разные типы врагов через `EnemyType`
- Использует маршруты (`Route`) для движения
- При уничтожении генерирует бонусы

### 5. Компоненты поведения (стратегии)

#### BehMove.cs
**Назначение**: Абстрактный базовый класс для всех стратегий движения.
**Реализации**:
- `BehEnMoveStandartBounce` - стандартное движение с отскоком от границ
- `BehEnMoveSwarm` - движение в рое
- `BehMoveGravityFall` - падение с гравитацией
- `BehLinearMove` - линейное движение
- `BehMoveNone` - отсутствие движения

#### ObjBehShoot.cs, ObjBehCollision.cs, ObjBehDraw.cs
Различные стратегии для стрельбы, столкновений и отрисовки.

### 6. Оружие (Weapons/)

#### Weapon.cs
**Назначение**: Базовый класс для всего оружия.
**Особенности**:
- Использует `WeaponOptions` для параметров
- Поддерживает разные типы оружия через `WeaponType`
- Реализует стрельбу очередями и перезарядку

**Реализации**:
- `WeaponCannon` - базовое оружие
- `WeaponMinigun` - скорострельное оружие
- `WeaponLaser` - лазерное оружие
- `NoWeapon` - отсутствующее оружие

### 7. Игровой процесс (GamePlay.cs)

**Назначение**: Управление основным циклом игры и обработкой событий.
**Ключевые функции**:
- Управление списком всех объектов `allObjects`
- Обработка столкновений между объектами
- Спавн врагов, бонусов и спецэффектов
- Обработка конца игры (победа/поражение)

**Главный цикл игры**:
```csharp
public void Activity(float time)
{
    // Обновление всех объектов
    for (int i = 0; i < allObjects.Count; i++)
    {
        allObjects[i].Activity(time);
        
        // Проверка столкновений
        for (int z = 0; z < allObjects.Count; z++)
        {
            if (allObjects[i] == allObjects[z]) continue;
            if (allObjects[i].coll.CheckCollision(allObjects[z]))
                allObjects[z].Collision(allObjects[i]);
        }
        
        // Удаление объектов
        if (allObjects[i].needToDelete == true)
        {
            // обработка уничтожения врага (бонусы, эффекты)
            allObjects[i].Delete();
            allObjects.Remove(allObjects[i]);
            i--;
        }
    }
}
```

### 8. Команды (Commands/)

**Назначение**: Реализация паттерна Команда для управления игрой.
**Ключевые команды**:
- `MainMenu`, `Win`, `Lose` - управление состояниями игры
- `StartNextLevel` - переход на следующий уровень
- `Pause`, `Resume` - управление паузой
- `SpawnRandomBonus`, `SpawnSFX` - создание объектов

### 9. Мир (World.cs)

**Назначение**: Матрица игрового поля для движения юнитов.
**Особенности**:
- Разбивает игровое поле на ячейки (90x90 пикселей)
- Позволяет получить координаты любой ячейки
- Используется для позиционирования объектов и маршрутов

### 10. Сцены (Scenes/)

**Назначение**: Различные игровые экраны на CocosSharp.
**Реализации**:
- `SceneMainMenu` - главное меню
- `SceneGame` - основной игровой экран
- `SceneNextLevel`, `SceneWin`, `SceneLose` - экраны между уровнями

## Архитектурные паттерны

### Паттерн Стратегия
Используется для реализации гибкого поведения объектов:
- Движение: `BehMove` и его наследники
- Стрельба: `ObjBehShoot` и его наследники
- Отрисовка: `ObjBehDraw` и его наследники

### Паттерн Команда
Используется для управления игрой и состояниями:
- Классы в директории `Commands/`
- Интерфейс `ICommand` для всех команд

### Паттерн Состояние
Используется для:
- Состояний игры (`IGameState`)
- AI врагов (`AIState`)

### Фабричный паттерн
Используется для создания объектов:
- Фабрики в директории `Factories/`

## Ключевые взаимосвязи

1. **GameManager** управляет **GamePlay**, который содержит список всех **GameObject**
2. **GameObject** использует компоненты-стратегии для поведения
3. **PlayerShip** и **Enemy** наследуются от **GameObject**
4. **Weapon** используется **GameObject** для стрельбы
5. **Commands** изменяют состояния игры через **GameManager**
6. **World** предоставляет координатную сетку для позиционирования объектов

## Специфические особенности реализации

### MonoBehavior-подобный паттерн
- `Activity(float time)` как аналог `Update()` в Unity
- Использование CocosSharp `CCNode` как базового класса

### Управление коллизиями
- Двойной цикл в `GamePlay.Activity()` для проверки всех столкновений
- Проверка столкновений через компоненты `ObjBehCollision`

### Управление удалением объектов
- Флаг `needToDelete` для отложенного удаления
- Обработка удаления в основном цикле игры

### Событийная система
- `GameEventDirector` и `LvlEventDirector` для управления событиями
- Подписка на события через делегаты

## Потенциальные сложности при миграции

1. **Иерархия CCNode**: В MonoGame нет встроенной иерархии объектов, нужно будет реализовать свою
2. **Расписание действий (Schedule)**: В CocosSharp есть встроенный scheduler, в MonoGame нужно будет реализовать свой
3. **Система координат**: Возможно потребуется адаптация системы координат
4. **Паттерн Стратегия**: Реализация компонентов требует аккуратного переноса
5. **Управление памятью**: CocosSharp использует референсный подсчет, MonoGame - .NET GC
